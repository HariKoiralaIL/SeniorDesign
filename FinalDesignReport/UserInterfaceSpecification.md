User Interface Specification:
Since our project is a game, the user interface (UI) plays a critical role in ensuring smooth interaction and an enjoyable user experience. Our UI includes the Main Menu, Options Menu, In-Game Skill Bar, Health Bar, and Pause Menu.
Design Philosophy

The UI design is based on the principle of simplicity. Our goal was to make the game intuitive — players should be able to start the game, pause, and adjust settings without confusion. A simple and user-friendly interface helps create a good first impression and supports player immersion.
Main Menu

Upon launching the game, players are presented with the Main Menu, which includes:
    Play – Starts the game.
    Options – Opens the settings menu.
    Credits – Displays team or contributor information.
    Quit – Exits the game.

Each button clearly communicates its function, requiring no explanation, which reinforces our simplicity-first approach.
Options Menu


The Options Menu includes:
    Volume – Adjusts the game’s audio volume.
    Resolution Setting – Lets players change the screen resolution.
    Fullscreen Toggle – Enables or disables fullscreen mode.
    Back Button – Returns to the Main Menu.


In-Game UI
During gameplay, players interact with the following UI elements:
    Skill Bar – Displays four usable skills with corresponding keys (e.g., X, Z). Skills include cooldown indicators.
    Health Bar – Dynamically updates based on damage taken or health gained.


Pause Menu
Pressing the ESC Bytton during gameplay brings up the Pause Menu, which includes:
    Return – Resumes the game.
    Options – Opens the Options Menu.
    Return to Title – Returns to the Main Menu.
    Quit – Exits the game.


Death Screen
When the player’s health reaches zero, a death screen appears with an option to Retry, allowing the player to restart the game and try again.
